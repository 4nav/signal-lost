# Signal Lost
A shortwave radio mystery where you tune into hidden transmissions, decode Morse code, and piece together what happened at a station that shouldn't exist. (NO SPOILERS!)

## Built With

React, TypeScript, Vite, and CSS.

# About
Signal Lost is a little radio mystery built around the idea of intercepting broadcasts from an unknown source. You operate an old shortwave receiver, searching through frequencies and trying to make sense of whatever comes through the static. The transmissions gradually reveal more about the station and the people behind them. I'll leave the rest for you to find out :3.

## Running Locally

```bash
git clone https://github.com/4nav/signal-lost
cd signal-lost
npm install
npm run dev
```

## Structure

- `components/` - UI components
- `data/` - Transmissions, stations, and hints
- `radio/` - Radio layout and intro tutorial
- `hooks/` - Custom React hooks
- `utils/` - Signal processing and Morse code logic
